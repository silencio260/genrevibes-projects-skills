# Optional promotion styles

Use these names when the user requests the style or references establish it.
They describe visual direction, not a requirement for every app.

| Name | Direction |
|---|---|
| `dark-premium-launcher` | Dark backgrounds, restrained orange glow, a large phone, short high-contrast copy. |
| `bright-play-aso` | Light backgrounds, clear feature headings, colorful accents, one or more phones. |
| `minimal-theme-showcase` | Sparse compositions, distinct themes, restrained copy, monochrome or paper-light surfaces. |

## Noir Glass Launcher

Use only when requested by name, a close-match request, or the supplied references.
Aliases include “black and white aura,” “dark aura setup,” and “noir glass.”
A generic request for a dark design is not enough to select this preset.

- [Neon](noir-glass-launcher/noir-glass-launcher-neon.png): dark glass with restrained colored light.
- [Mono](noir-glass-launcher/noir-glass-launcher-mono-dark.png): grayscale phone and studio composition.
- [Clean](noir-glass-launcher/noir-glass-launcher-clean-light.png): light background with graphite/glass elements.

Open the relevant reference before using it. Preserve its composition and material
style while showing the target app's real features. Do not add launcher widgets
or docks to another app unless that is the requested concept. Brand inclusion
follows the user brief; references do not authorize copying another identity.
